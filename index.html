    How it works
    
GSAP staggers numbers, the page paints them

    

      

        

          
1. One object per strip

          
GSAP can tween any object, not only elements. strips is an array of { progress: 0 }. Passing the whole array to .to() with stagger gives every strip its own delayed, eased progress from 0 to 1.

        

        

          
2. Paint every frame

          
In the timeline's onUpdate, each strip becomes a band from stripStart to stripStart + stripSize × progress. The mask version writes those bands as gradient hard stops. The canvas version fills them as rectangles and draws the image into them.

        

        

          
3. One function, any number of images

          
The code wraps the setup in createMaskReveal() or createCanvasReveal(). Single mode calls it once with a pinned track. Multiple mode calls it for every matching element, each with its own start and end.

        

        

          
Why three versions?

          
GSAP + mask is the most flexible. Pure CSS needs no library but has less browser support for scrubbing. Canvas behaves the same in every browser and gives per-pixel control, at the cost of turning the image into pixels.
